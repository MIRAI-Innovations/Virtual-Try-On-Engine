## Feature Extraction Details
--------------------------------

Automated Features (MediaPipe-based):

1. Body Shape Classification
   - Method: Shoulder-to-hip ratio analysis
   - Categories: "Inverted Triangle", "Hourglass", "Rectangle"
   - Processing time: <100ms

2. Face Shape Classification
   - Method: Face width-to-height ratio
   - Categories: "Oval", "Round", "Square"
   - Landmarks used: 468 face mesh points

3. Skin Tone Detection
   - Method: RGB intensity averaging on cheek ROI
   - Categories: "Fair", "Medium", "Dark"
   - Thresholds: Fair >170, Medium 100-170, Dark <100


## Data Collection Schema
----------------------------

CSV Format (trial_data.csv):
- Height (cm)
- Age (years)
- Gender (Male/Female)
- Style Preference (Casual/Formal/etc.)
- Body Shape (automated)
- Face Shape (automated)
- Skin Tone (automated)
- Age Group (derived: Teen/Adult/Mature)
- Arm Preference (derived: Cover/Any)
- Subject File (image path)
- Cloth File (image path)
- Result File (output path)


## Command-Line Usage
-----------------------

Basic:
  python run_trial.py

Advanced:
  python run_trial.py --subject path/to/image.jpg --cloth_dir path/to/clothes/

API Client:
  python run_vton_api.py


## System Requirements
------------------------

- Python 3.8 or higher

## Installation Steps
-----------------------

1. Clone repository:
   git clone https://github.com/StillDuxk/Mirai_tryon_Mirror.git

2. Navigate to directory:
   cd Mirai_tryon_Mirror

3. Install dependencies:
   pip install gradio-client==1.5.0 mediapipe==0.10.31 opencv-python pandas numpy Pillow

4. Run trial:
   python run_trial.py


## Troubleshooting Reference
------------------------------

Common Issues:
1. SSL Connection Errors → Automatic retry (3x per provider)
2. MediaPipe Import Errors → pip install mediapipe==0.10.31
3. No Cloth Images Found → Check datasets/test/cloth/ directory
4. Gradio Client Timeout → System switches to backup provider
